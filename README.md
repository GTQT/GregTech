## Welcome to GregTech CE: MeowmelMuku
### What is this?
This is a fork version of GregTech CE Unofficial (GTCEu) based on version 2.9, dedicated to enriching more content and ensuring that addon development is not affected by frequent underlying changes in the original mod.

### About This Fork
This fork builds upon the solid foundation of GTCEu 2.9 while introducing significant enhancements and optimizations:

### Project Goal
To provide a stable and feature-rich GregTech experience based on GTCEu 2.9, focusing on content expansion while maintaining compatibility with existing addons and preventing disruptions from core mod changes.
