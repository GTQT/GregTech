# 新型储能系统设计文档

## 概述

本文档提出两种新的 GregTech 多方块储能系统：
1. **超导磁储能环 (SMES, Superconducting Magnetic Energy Storage)** — 超低损耗磁场储能
2. **氧化还原液流电池 (RFB, Redox Flow Battery)** — 基于流体的化学储能

两者均作为现有电力变电站 (PSS) 的替代/补充方案，各自具有独特的游戏机制、权衡取舍和科技树定位。

---

## 第一部分：超导磁储能环 (SMES)

### 1.1 现实原理

SMES 将能量存储在直流电流通过超导线圈所产生的磁场中。由于线圈在临界温度以下具有零电阻，电流可以无限循环而几乎没有损耗。SMES 具备以下特点：
- 近乎瞬时的充放电响应（微秒级）
- 极高的往返效率（>95%）
- 极高的功率密度（兆瓦级输出）
- 需要低温冷却基础设施

### 1.2 游戏设计理念

| 方面 | SMES | PSS（现有） |
|------|------|------------|
| 核心优势 | 极高功率 I/O 速率，近零被动损耗 | 超大容量（BigInteger） |
| 核心代价 | 持续消耗低温冷却剂 | 被动损耗（每24小时1%） |
| 科技树定位 | LuV~UV 阶段入门 | EV 阶段入门 |
| 扩展方式 | 有限容量但超大安培数 | 巨大容量，中等安培数 |
| 风险 | 冷却剂断供 → 灾难性能量释放（爆炸） | 安全（仅有损耗） |

**定位**：SMES 并非用于替代 PSS 的大容量存储。它的优势是作为**高功率缓冲器**——适用于短时间内需要巨大功率的机器（如：聚变反应堆启动、质量制造器脉冲、研究站脉冲）。可以将其理解为超级电容 vs PSS 作为仓库。

### 1.3 GT 电压等级与科技进程

| 等级 | GT 等级 | 线圈材料 | 冷却剂 | 最大存储 | 最大 I/O 速率 |
|------|---------|----------|--------|----------|--------------|
| Mk I | LuV (6) | NbTi（铌钛合金） | 液氦 | 10亿 EU | 4A @ LuV (131,072 EU/t × 4) |
| Mk II | ZPM (7) | 钒镓合金 | 液氦 | 160亿 EU | 16A @ ZPM (131,072 × 8 × 16) |
| Mk III | UV (8) | YBCO（钇钡铜氧） | 液氮* | 2560亿 EU | 64A @ UV |
| Mk IV | UHV (9) | 铕 | 液氦 | 4万亿 EU | 256A @ UHV |

*YBCO 是"高温超导体"——临界温度约92K，因此液氮即可满足需求（比液氦更便宜）。

**关键方块：**

| 冷却剂输入仓 | 接受液氦或液氮 |
| 冷却剂输出仓 | 输出升温后的气体（氦气/氮气） |
| 能量仓（I/O） | 支持标准能量仓、激光仓 |
| 维护仓 | 必须 |

### 1.5 机制

#### 1.5.1 冷却剂消耗

SMES **持续**消耗低温冷却剂，消耗量与储存的能量成正比：

```
基础冷却剂速率 = (storedEnergy / maxCapacity) × coolantPerTick × coilCount

其中：
- coolantPerTick(液氦) = 满载时每线圈方块 1 mB/t
- coolantPerTick(液氮) = 满载时每线圈方块 4 mB/t（更便宜但体积更大）
```

当储存能量为0时，冷却剂消耗降至最低待机速率（每线圈 0.1 mB/t）。

**冷却剂流向：**
```
液氦（输入） → [SMES 内部吸热] → 氦气（输出）
液氮（输入） → [SMES 内部吸热] → 氮气（输出）
```

输出气体可循环利用：氦气 → 压缩机/低温蒸馏 → 液氦（需要额外能量）。

#### 1.5.2 被动损耗

与 PSS 的百分比被动损耗不同，SMES 在正常冷却时具有**近零被动损耗**：
- 正常冷却时：0 EU/t 被动损耗（超导体零电阻）
- 冷却剂耗尽时：能量以每秒5%的速率衰减，并产生热量

#### 1.5.3 冷却剂失效 / 淬火事件

如果在储存能量时冷却剂耗尽：

1. **警告阶段**（5秒）：残余冷却剂内部缓冲。机器发出粒子效果和警告声音。
2. **淬火阶段**：温度升至临界点以上 → 超导体变为电阻性 → 储存能量转化为热量
3. **后果**：
   - 储存 < 25% 容量：能量直接消失，结构受损
   - 储存 25-75%：中等爆炸（按等级缩放），结构部分损坏
   - 储存 > 75%：大型爆炸（等效于 `GTUtility.getExplosionPower(voltage) * 2`），结构摧毁

这创造了有意义的风险/回报动态。玩家必须确保可靠的冷却剂供应。

#### 1.5.4 充放电行为

- **即时响应**：不同于 PSS 从仓室逐tick传输，SMES 可以立即输出全部安培数
- **无内部缓冲延迟**：能量直接存储在线圈磁场中
- **双向性**：同一仓室可同时用作输入和输出（通过控制器 GUI 配置）

## 第二部分：氧化还原液流电池 (RFB)

### 2.1 现实原理

氧化还原液流电池将能量存储在外部储罐中的溶解化学物质（电解液）中。通过将充电后的电解液泵入储罐来储能，通过将其泵回电化学电池来回收能量。关键特性：
- 容量随储罐大小扩展（独立于功率额定值）
- 功率额定值随电池堆大小扩展（独立于容量）
- 超长循环寿命（无固体电极退化）
- 能量密度低但可扩展性极佳
- 常见类型：全钒液流 (VRFB)、锌溴、铁铬

### 2.2 游戏设计理念

| 方面 | RFB | PSS（现有） | SMES |
|------|-----|------------|------|
| 核心优势 | 容量/功率解耦，零被动损耗，易于升级 | 巨大容量 | 高功率 I/O |
| 核心代价 | 复杂的流体物流，较大物理占地 | 被动损耗 | 低温冷却剂 |
| 科技树定位 | HV~IV 入门（比 PSS 更早可用） | EV 入门 | LuV 入门 |
| 扩展方式 | 加储罐扩容量，加电池堆扩功率 | 加电池层 | 加线圈方块 |
| 风险 | 电解液泄漏 = 储能损失（不会爆炸） | 安全 | 爆炸 |

**定位**：RFB 位于基础电池和 PSS 之间。它是第一个"工业规模"的储能选项。其独特机制是**能量以流体形式存储**——玩家可以真正"看到"自己的能量（充电电解液储罐）。这创造了有趣的物流玩法。

### 2.3 电解液体系

#### 流体类型

| 电解液对 | GT 等级 | 能量密度 | 电压 | 配方链 |
|---------|---------|----------|------|--------|
| 铁-铬 | HV (3) | 20 EU/mB | 128V | 铁 + 铬 + 盐酸 |
| 硫酸钒 | EV (4) | 80 EU/mB | 512V | 钒 + 硫酸 |
| 锌-溴 | EV (4) | 120 EU/mB | 512V | 锌 + 溴 + 氢溴酸 |
| 硅岩悬浮液 | IV (5) | 500 EU/mB | 2048V | 硅岩粉 + 特殊酸 |
| 三元素胶体 | LuV (6) | 2000 EU/mB | 8192V | 三元素 + 等离子处理 |

每种电解液系统使用**两种流体**——充电态和放电态：

```
充电钒电解液 ←→ 放电钒电解液
（存储能量）      （耗尽态）
```

总体积守恒：充电时将放电态转化为充电态，放电时将充电态转化为放电态。

### 2.5 机制

#### 2.5.1 以流体形式储能

核心创新：**能量就是流体**。

```
容量 (EU) = 充电电解液体积 (mB) × 能量密度 (EU/mB)

示例（钒，EV 等级）：
  - 16个储罐方块 × 64,000 mB = 1,024,000 mB 总容量
  - 按 80 EU/mB → 最大存储 = 81,920,000 EU（约8200万 EU）
  - 流体状态：初始为 1,024,000 mB 放电钒电解液
  - 充满后：1,024,000 mB 充电钒电解液，0 mB 放电态
```

#### 2.5.2 充放电速率

功率速率由**电极堆**方块决定：

```
每电极最大 EU/t = V[tier] × 2A

示例（EV 等级，8个电极堆）：
  8 × 512 × 2 = 8,192 EU/t 最大充放电速率
```

#### 2.5.3 流体转化速率

充放电过程中，流体在充电态和放电态之间转换：

```
每 tick 转化的流体量 = (实际 EU/t 传输量) / 能量密度

示例：以 4,096 EU/t 速率对钒电解液（80 EU/mB）充电：
  4,096 / 80 = 51.2 mB/t 从放电态转化为充电态
```

#### 2.5.4 效率

往返效率取决于电极质量和电解液类型：

| 电解液 | 充电效率 | 放电效率 | 往返效率 |
|--------|---------|---------|---------|
| 铁-铬 | 92% | 92% | 84.6% |
| 硫酸钒 | 95% | 95% | 90.3% |
| 锌-溴 | 93% | 93% | 86.5% |
| 硅岩 | 98% | 98% | 96.0% |
| 三元素 | 99% | 99% | 98.0% |

损失的能量被消除（代表电化学过程中的热损耗）。

#### 2.5.5 零被动损耗

与 PSS 不同，RFB **没有被动损耗**。储罐中的充电电解液可以无限期保持其能量。这是间歇性/长期存储的关键优势。

#### 2.5.6 电解液降解（可选机制）

经过多次充放电循环，少量电解液会降解：

```
降解率：每次完整充电循环，循环体积的 0.01%
降解流体："降解的[类型]电解液"（可在化学反应器中再处理）
```

这创造了持续的材料成本，但不会惩罚空闲存储。

### 3.1 与现有系统的兼容性

- 支持标准能量仓（2A/4A/16A/64A）
- 支持激光仓
- 可通过无线控制器连接到无线能量网络
- 可配合主动变压器进行电压转换

## 第四部分：游戏流程示例

### 4.1 SMES 使用场景

一位处于 LuV 阶段的玩家需要为聚变反应堆供电（启动成本：1.6亿 EU）：

1. 建造含有16个线圈方块的 SMES → 160亿 EU 容量
2. 通过 16A LuV 能量仓连接基地电网
3. 设置液氦生产线：氦气 → 真空冷冻机 → 液氦
4. 将液氦管道输入 SMES 冷却剂输入仓，氦气输出管道回到冷冻机
5. SMES 从基地电网持续充电
6. 当聚变反应堆需要启动能量时 → SMES 以全安培数瞬间输出 1.6亿 EU
7. 聚变启动发电后 → SMES 从聚变多余输出中恢复充能

**风险事件**：如果真空冷冻机故障或氦供应中断：
- 玩家有约5秒警告时间（粒子效果、声音）
- 必须选择：恢复冷却剂供应，或紧急向电网放电
- 若都不做：淬火 → 储存能量转化为爆炸

### 4.2 RFB 使用场景

一位处于 HV 阶段的玩家想要他的第一个工业规模储能装置：

1. 在化学反应器中生产铁-铬电解液
2. 建造 RFB 多方块（最小 7×3×7）
3. 通过流体输入仓填入放电铁铬电解液
4. 连接 HV 发电机（蒸汽涡轮等）
5. 观察发电机为电池充电：放电流体转化为充电流体
6. 夜间（太阳能下线）或高峰需求时：电池放电，充电态 → 放电态
7. 能量以流体形式存储，意味着你甚至可以**将充电电解液通过管道传输到另一个远程 RFB**！

**独特玩法**：
- 玩家可以通过运输充电电解液（流体储罐/储罐矿车）来运输能量
- 升级方式：将铁铬电解液替换为钒电解液 = 容量即时提升（同一结构）
- 视觉反馈：储罐流体颜色随充电状态变化

## 第五部分：优势总结

### 为什么在 PSS 已存在的情况下还要添加这些？

1. **填补科技进程空白**：RFB 填补了 HV~EV 阶段缺少多方块存储的空缺；SMES 填补了"高功率瞬时供电"的定位
2. **不同的游戏机制**：PSS 是被动的（"建好就忘"）。SMES 需要主动管理冷却系统。RFB 创造了流体物流玩法。
3. **风险/回报**：SMES 爆炸机制增加了有意义的危险。RFB 的能量即流体创造了运输可能性。
4. **现实世界教育**：两种系统都反映了实际的储能技术，符合 GT 的科普教育理念
5. **兼容性**：两者都在现有的 EU 系统和能量网络基础设施内运作
