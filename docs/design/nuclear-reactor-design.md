# 核反应堆设计文档

## 概述

本文档描述了GregTech中计划加入的核反应堆类型，参考了现实核物理、GT5/GTNH设计以及幻想/科幻元素。
目标是创建一个丰富的、分层级的核能系统，提供有意义的科技进展和游戏深度。

## 第二部分：反应堆类型（裂变）

### 等级1：气冷堆（AGR）- HV

| 参数   | 数值           |
| ---- | ------------ |
| GT等级 | HV (3)       |
| 燃料   | 天然铀棒 / 低浓缩铀棒 |
| 冷却剂  | CO2气体        |
| 慢化剂  | 石墨方块（结构件）    |
| 输出   | 蒸汽（低温）       |
| 热效率  | \~30%        |
| 安全性  | 非常高（低功率密度）   |

**设计理念：**

- 入门级核反应堆，在HV阶段即可使用
- 使用未浓缩或低浓缩铀——节省昂贵的浓缩工序
- 输出功率低但非常安全，燃料持续时间极长
- 基于英国AGR/Magnox设计
- 石墨方块同时作为慢化剂和结构材料组成多方块结构

**燃料循环：**

```
天然铀 --> [AGR气冷堆] --> 贫铀 + 微量Pu-239
                           （低燃耗，可后处理回收）
```

**游戏机制：**

- 中子代时间慢（非常稳定，类别0）
- 每tick热量输出低，但燃料持续时间极长
- CO2必须循环流动（流体输入/输出）
- 蒸汽输出接蒸汽涡轮机发电

***

### 等级2：压水堆（PWR）- EV

| 参数   | 数值                  |
| ---- | ------------------- |
| GT等级 | EV (4)              |
| 燃料   | 浓缩铀-235燃料棒（3-5%富集度） |
| 冷却剂  | 加压蒸馏水               |
| 慢化剂  | 水（自慢化）              |
| 输出   | 过热蒸汽                |
| 热效率  | \~33%               |
| 安全性  | 中等（高压系统）            |

**设计理念：**

- 主力堆型，功率/复杂度比最高
- 基于现实中最常见的堆型（西屋PWR）
- 需要铀浓缩基础设施（UF6离心机链已在代码中存在）
- 双回路设计：一回路加压水将热量传递给二回路蒸汽

**燃料循环：**

```
浓缩U-235（3-5%）--> [PWR压水堆] --> 乏燃料（U-238 + Pu-239 + 裂变产物）
                                       |
                                       v
                                [后处理] --> Pu-239（用于MOX/快堆）
                                         --> 贫铀
                                         --> 裂变产物废料
```

**游戏机制：**

- 中等中子代时间（类别1，较稳定）
- 需要加压水系统（特殊流体管道或内部压力机制）
- 控制棒机制：可调节功率水平
- 可使用MOX燃料获得更高输出但持续时间缩短

### 等级2B：沸水堆（BWR）- EV

| 参数   | 数值                  |
| ---- | ------------------- |
| GT等级 | EV (4)              |
| 燃料   | 浓缩铀-235燃料棒（3-5%富集度） |
| 冷却剂  | 水/蒸汽（直接循环）          |
| 慢化剂  | 水                   |
| 输出   | 蒸汽（直接输出，无热交换器）      |
| 热效率  | \~33%               |
| 安全性  | 中偏低（直接蒸汽循环，蒸汽带放射性）  |

**设计理念：**

- 比PWR更简单（单回路，无蒸汽发生器）
- 建造成本略低，但蒸汽带放射性（受污染）
- 基于GE沸水堆设计
- 权衡：结构更简单但污染蒸汽输出需要特殊处理

**燃料循环：** 与PWR相同

**游戏机制：**

- 多方块结构比PWR更简单（无二回路）
- 蒸汽输出为"受污染蒸汽"——排放前需要过滤
- 效率略高但有放射性废气副产物

### 等级2C：重水堆（PHWR/CANDU）- EV

| 参数   | 数值          |
| ---- | ----------- |
| GT等级 | EV (4)      |
| 燃料   | 天然铀棒 或 钍燃料棒 |
| 冷却剂  | 重水（D2O）     |
| 慢化剂  | 重水          |
| 输出   | 蒸汽          |
| 热效率  | \~30%       |
| 安全性  | 高           |

**设计理念：**

- 可使用天然铀（无需浓缩！）——替代路线
- 非常适合钍燃料循环（Th-232增殖）
- 基于加拿大CANDU反应堆
- 重水生产昂贵但节省了浓缩成本
- 在线换料能力（不需要停堆换燃料）

**燃料循环：**

```
天然铀 --> [PHWR重水堆] --> 贫铀 + Pu-239（转换比更高）

钍-232 --> [PHWR，配合U-235驱动燃料] --> U-233（增殖产物）+ 钍废料
                                           |
                                           v
                                    [后处理] --> U-233燃料供熔盐堆使用
```

**游戏机制：**

- 需要重水生产（大量水的电解）
- 可接受钍棒作为增殖包壳材料
- 在线换料：不需要停堆即可更换燃料（特殊机制）
- 功率密度较低但燃料利用率很高

### 等级3：快中子增殖堆（FBR）- IV

| 参数   | 数值                      |
| ---- | ----------------------- |
| GT等级 | IV (5)                  |
| 燃料   | MOX燃料棒（PuO2 + UO2）      |
| 冷却剂  | 液态钠（Na）                 |
| 慢化剂  | 无（快中子能谱）                |
| 输出   | 高温热量 --> 钠/水热交换器 --> 蒸汽 |
| 热效率  | \~40%                   |
| 安全性  | 低（钠火灾风险）                |
| 特殊   | 增殖的燃料比消耗的多！             |

**设计理念：**

- 常规核技术的巅峰
- 使用快中子（未慢化）——无慢化剂方块
- 从U-238包壳棒增殖Pu-239（产出的可裂变材料比消耗的多！）
- 液态钠冷却剂：传热极佳但遇水剧烈反应
- 基于法国超级凤凰堆、俄罗斯BN-800
- GT5 MOX燃料机制：温度越高效率加成越大

**燃料循环：**

```
MOX（Pu-239 + U-238）--> [FBR快堆] --> 乏MOX + 新Pu-239（从U-238包壳增殖）
                                         |
        增殖比 > 1.0 -------------------|
        （产出的Pu比消耗的多）
                                         |
                                         v
                                  [后处理] --> 新鲜Pu-239 --> 新MOX燃料
                                           --> 次锕系元素（Np, Am, Cm）
```

**游戏机制：**

- 结构中无慢化剂方块（快中子能谱）
- U-238包壳棒环绕燃料棒：随时间转化为Pu-239
- 液态钠冷却剂：绝对不能接触水（爆炸机制）
- 钠-水热交换器作为独立结构/组件
- MOX燃料加成：反应堆温度越高输出越大（类似IC2 MOX机制）
- 增殖产出：周期性产出Pu-239粒/粉作为副产物

### 等级3B：熔盐堆（MSR）- IV

| 参数   | 数值                              |
| ---- | ------------------------------- |
| GT等级 | IV (5)                          |
| 燃料   | UF4或ThF4溶解在FLiBe熔盐中（流体，非固体燃料棒！） |
| 冷却剂  | FLiBe熔盐（同时是燃料载体）                |
| 慢化剂  | 石墨                              |
| 输出   | 高温熔盐 --> 热交换器 --> 蒸汽或工艺热        |
| 热效率  | \~45%                           |
| 安全性  | 非常高（固有安全——负温度系数）                |
| 特殊   | 液态燃料、在线后处理、钍循环                  |

**设计理念：**

- 革命性反应堆，燃料溶解在冷却剂中
- 没有燃料棒！燃料以流体形式输入（含裂变材料的熔盐）
- 基于美国橡树岭MSRE和中国TMSR-LF1
- 钍燃料循环：Th-232吸收中子 --> Pa-233 --> U-233
- 在线后处理：运行中连续去除裂变产物
- 固有安全：温度升高时盐膨胀，反应性下降，自调节
- 常压运行（无需高压容器）
- 高温输出（700°C+）可用于制氢、化工过程

**燃料循环：**

```
FLiBe + ThF4（流体输入）--> [MSR熔盐堆] --> FLiBe + 裂变产物（流体输出）
     ^                                          |
     |                                          v
     |                              [化学反应器 - 在线后处理]
     |                                          |
     |                                          v
     +------ 回收的FLiBe + U-233 <--------------+
                                                |
                                                v
                                      短寿命废物（固化处理）
```

**游戏机制：**

- 流体燃料输入（非物品/棒）——在所有反应堆中独一无二！
- 需要FLiBe熔盐生产链（LiF + BeF2）
- 裂变材料溶解态：UF4或ThF4混入FLiBe
- 输出为受污染的高温盐 --> 需要化学后处理
- 可与化学反应器耦合进行在线废物分离
- 钍增殖：输入ThF4，随时间在盐中产生U-233
- 冻结塞机制：断电时盐自动排入安全罐（防止熔毁）
- 超高温输出：可直接为高温化学过程供热

### 等级4：高温气冷堆（HTGR）- LuV

| 参数   | 数值                             |
| ---- | ------------------------------ |
| GT等级 | LuV (6)                        |
| 燃料   | TRISO燃料球（陶瓷包覆的浓缩铀微球）           |
| 冷却剂  | 氦气                             |
| 慢化剂  | 石墨                             |
| 输出   | 超高温氦气（900-1000°C）--> 气体涡轮机或工艺热 |
| 热效率  | \~48%（气体涡轮直接循环）                |
| 安全性  | 极高（陶瓷包覆层封装所有裂变产物）              |
| 特殊   | 超高温度，可驱动化工过程                   |

**设计理念：**

- 基于中国HTR-PM和德国AVR
- TRISO燃料：铀核心外包裹多层SiC和热解碳
- 每个燃料颗粒都是自身的包容容器——不可能熔毁
- 氦气冷却剂化学惰性（无钠火灾、无蒸汽爆炸）
- 超高温使得可以直接使用气体涡轮循环（无需蒸汽！）
- 可为工业过程提供热量：制氢、钢铁还原

**燃料循环：**

```
浓缩U-235 --> [TRISO制造] --> TRISO燃料球
                                |
                                v
                         [HTGR高温气冷堆] --> 乏TRISO燃料球
                                              （极其稳定的废物形态）
```

**游戏机制：**

- TRISO燃料球作为特殊物品（由浓缩铀 + SiC + 碳合成）
- 连续装卸燃料球（在线换料，类似CANDU）
- 氦气冷却回路（惰性，无爆炸风险）
- 超高温输出可直接供应：
  - 气体涡轮机（最高电效率）
  - 热化学制氢
  - 高温高炉加速
- 乏TRISO是非常稳定的废物（无需后处理，直接处置）

### 等级4B：铅铋快堆（LBFR）- LuV

| 参数   | 数值                      |
| ---- | ----------------------- |
| GT等级 | LuV (6)                 |
| 燃料   | 高浓缩铀棒 / 次锕系元素棒          |
| 冷却剂  | 铅铋共晶合金（Pb-Bi合金，熔点125°C） |
| 慢化剂  | 无（快中子能谱）                |
| 输出   | 中高温热量                   |
| 热效率  | \~42%                   |
| 安全性  | 高（Pb-Bi不与水/空气反应）        |
| 特殊   | 超长堆芯寿命，可嬗变              |

**设计理念：**

- 基于俄罗斯BREST-300和潜艇反应堆设计
- 铅铋冷却剂：不与水反应（不像钠），密度很大
- 快中子能谱使得可以嬗变长寿命废物
- 密封堆芯设计：可连续运行数十年不换料
- 但是：Pb-Bi在中子辐照下会产生Po-210（高放射性）
- 可以"烧掉"次锕系元素（Np, Am, Cm）作为燃料，销毁长寿命废物

**燃料循环：**

```
高浓缩铀或次锕系燃料 --> [LBFR铅铋堆] --> 短寿命裂变产物
                                            + Po-210污染的冷却剂
                                            + 乏燃料（嬗变后的锕系）
```

**游戏机制：**

- 极长燃料持续时间（密封堆芯概念）
- Pb-Bi冷却剂流体（铅+铋合金，材料已存在于代码库中）
- 无钠-水爆炸风险，但有Po-210副产物（放射性废液）
- 可接受次锕系元素燃料棒（用于废物销毁）
- 前期建造成本高，维护需求极低
- 嬗变输出：将长寿命废物转化为短寿命废物

### 等级5：钍基液态金属堆（Th-LMR）- ZPM

| 参数   | 数值              |

| 输出   | 极高温热量           |
| 热效率  | \~50%           |
| 安全性  | 高               |

**设计理念：**

- 结合快谱增殖与钍的优势

- 非常高的效率，低废物
- 顶级等级：建造昂贵但运行后燃料几乎免费

### 等级5B：加速器驱动次临界系统（ADS）- ZPM

| 参数   | 数值                            |
| ---- | ----------------------------- |
| GT等级 | ZPM (7)                       |
| 燃料   | 次锕系元素燃料（镎、镅、锔）                |
| 冷却剂  | 液态铅                           |
| 中子源  | 粒子加速器（散裂靶）— 需要EU输入            |
| 输出   | 热量 + 嬗变后的废物                   |
| 效率   | 净负或极低正值（目的是废物销毁）              |
| 安全性  | 终极安全（次临界 = 不可能链式反应，加速器关闭立即停堆） |
| 特殊   | 核废料销毁机器                       |

**设计理念：**

- 主要不是发电机——而是废物销毁器
- 烧掉长寿命核废物（Np-237, Am-241, Cm-244），否则这些会存在数百万年
- 次临界：燃料自身不能维持链式反应
- 需要外部中子源（粒子加速器轰击铅靶 = 散裂反应）
- 将百万年级废物转化为百年级废物
- 基于比利时MYRRHA和日本JAEA设计

**燃料循环：**

```
[EU输入] --> [粒子加速器] --> 散裂中子
                               |
                               v
次锕系元素（Np/Am/Cm）------> [ADS反应堆] --> 短寿命裂变产物
（百万年半衰期）                               （百年级半衰期）
                                               + 少量热量/EU
```

**游戏机制：**

- 需要EU输入才能运行（加速器消耗电力）
- 净能量输出很小或为零（主要目的是废物处理）
- 将长寿命废物物品转化为短寿命废物物品
- 绝对不可能熔毁（设计上就是次临界的）
- 适用于积累了大量核废料的玩家
- 核燃料循环的最终闭环

***

### 等级6：硅岩反应堆（Naquadah Reactor）- UV（幻想）

| 参数   | 数值               |
| ---- | ---------------- |
| GT等级 | UV (8)           |
| 燃料   | 浓缩硅岩燃料棒          |
| 冷却剂  | 超临界氦 / 硅岩合金回路    |
| 慢化剂  | 中子素反射层           |
| 输出   | 直接EU（类似GT5硅岩反应堆） |
| 效率   | >90%（直接能量转换）     |
| 安全性  | 极低（超能硅岩爆炸风险）     |
| 特殊   | 游戏中最高裂变EU输出      |

**设计理念：**

- 灵感来自GT5/GTNH的幻想反应堆
- 硅岩具有异常核特性：每次裂变释放的能量远超任何现实材料
- 直接能量转换（此等级不需要蒸汽循环）
- 极其危险：失控会产生超能硅岩链式反应（巨大爆炸）
- 需要中子素反射层来包容中子通量
- 三元素结构组件用于辐射屏蔽
- 终局裂变电源（在聚变接管之前）

**燃料循环：**

```
浓缩硅岩 --> [硅岩反应堆] --> 贫化硅岩 + 巨量EU
                               |
                               v（如果失控）
                            超能硅岩爆炸（灾难性）

超能硅岩（作为包壳）--> 可增殖为更多浓缩硅岩（极危险！）
```

**游戏机制：**

- 所有裂变反应堆中最高EU/t输出
- 直接EU输出（无需蒸汽/涡轮机）
- 中子代时间：类别3（极其危险——快中子、短代时间）
- 冷却失败或中子通量超限时爆炸机制
- 需要：
  - 中子素外壳用于中子反射
  - 三元素板材用于辐射屏蔽
  - 硅岩合金管道用于冷却回路
- 贫化硅岩输出（可以极高成本重新浓缩）
