## 1. 概述

本文档描述了三台燃料电池多方块机器的概念设计：

| 机器名称 | 内部名称 | 类型 | 电压等级 | 科技基础 |
|---------|---------|------|---------|---------|
| 燃料电池阵列 | `fuel_cell_array` | 参数化变体（3 种变体） | MV ~ IV | 现实电化学 |
| 可逆固体氧化物电池 | `reversible_solid_oxide_cell` | 独立多方块 | LuV | 近未来科技 |
| 量子隧穿燃料电池 | `quantum_tunneling_fuel_cell` | 独立多方块 | ZPM | 科幻设定 |

### 设计原则

1. **燃料电池不是内燃机。** 它通过电化学反应将化学能转化为电能，而非热力燃烧。这意味着：
   - 理论效率高于热机（不受卡诺循环限制）
   - 运行更安静（电池堆本身无运动部件）
   - 燃料需求和副产物与燃烧发电完全不同

2. **燃料电池不是蓄电池。** 它需要持续供给燃料才能发电，不在内部储存能量。
   燃料电池更接近"发电引擎"，而非"能量罐头"。

3. **科技门槛** 由电化学材料定义：
   - 离子交换膜、陶瓷电解质、熔盐混合物
   - 催化剂材料（铂、镍、特种化合物）
   - 工作温度管理基础设施

## 2. 架构总览

```
                    燃料电池多方块家族
                    ================

    多方块 A                   多方块 B               多方块 C
    燃料电池阵列                rSOC                   量子隧穿燃料电池
    (ParametricFuelController) (独立多方块)            (独立多方块)
    |                          |                      |
    +-- 变体: DMFC (MV)        双模式:                 低温运行:
    +-- 变体: SOFC (HV~EV)      - 发电模式              - 接近绝对零度
    +-- 变体: MCFC (EV~IV)      - 电解模式              - 量子势垒穿透
                                                       - 氘/氚燃料
```

### 为什么这样划分？

- **DMFC/SOFC/MCFC** 共享相同的基本架构：一侧输入燃料，另一侧输入氧化剂，
  中间是电解质膜/层，输出电力。它们仅在工作温度、燃料类型和电解质材料上有所不同。
  变体系统可以干净地表达这些差异。

- **rSOC** 具有根本性不同的机制：可在发电和电解两种模式间切换。
  这种双向行为不适合单向"燃料→电力"的变体模型。

- **量子隧穿燃料电池** 基于完全不同的物理原理（量子力学而非电化学），
  且需要低温基础设施。它值得拥有独立的结构和逻辑。

## 3. 多方块 A：燃料电池阵列

### 3.1 共享结构与机制

#### 结构布局 (5×3×N，可变长度)

燃料电池阵列采用水平堆叠的电池层结构，模拟现实中多个单电池串联组成的
燃料电池堆(stack)。

```
正面视图（控制器面）：            侧面截面（单个电池层）：

  第 0 层     第 1~N 层     第 N+1 层      +---+---+---+---+---+
  (端盖)     (电池层)      (端盖)         | C | C | C | C | C |
                                          +---+---+---+---+---+
  CCCCC      CAEAC         CCCCC          | A | E | - | E | A |
  CCCCC      CAEAC         CCCCC          +---+---+---+---+---+
  CSCCC      CAEAC         CCCCC          | C | C | C | C | C |
                                          +---+---+---+---+---+

  S = 控制器
  C = 外壳（变体特定材质）/ 仓室位置
  A = 阳极通道方块（燃料侧）
  E = 电解质膜方块（变体特定）
  - = 阴极通道方块（氧化剂侧）
```

**可变长度：** 电池堆可重复 2 至 8 层（第 1~N 层）。
更多层 = 更高功率输出（线性缩放）。

#### 共享仓室配置

| 仓室类型 | 位置 | 数量 | 说明 |
|---------|------|------|-----|
| 流体输入仓（燃料） | 端盖 / 外壳 | 1~4 | 燃料供给 |
| 流体输入仓（氧化剂） | 端盖 / 外壳 | 1~2 | O₂ / 空气 / CO₂+O₂ |
| 流体输出仓（副产物） | 端盖 / 外壳 | 1~2 | H₂O / CO₂ / 废气 |
| **物品输入总线（催化剂）** | **端盖 / 外壳** | **1** | **催化剂板/粉输入，机器内部涂覆到电解质上** |
| 物品输出总线（废催化剂） | 端盖 / 外壳 | 0~1 | 催化剂耗尽后输出废催化剂粉 |
| 发电机仓 | 端盖 / 外壳 | 1~2 | EU 输出 |
| 维护仓 | 端盖 | 0~1 | 标准维护 |

#### 共享机制：催化剂涂覆

催化剂以物品形式通过 Input Bus 输入，机器内部自动将催化剂涂覆到电解质层上。
这模拟了现实中燃料电池催化剂层（Catalyst Layer）的制备过程。

**工作流程：**

1. **首次涂覆（必需）：** 机器组装成功后，必须先通过 Input Bus 输入催化剂物品。
   机器进入"催化剂涂覆"状态（持续约 10 秒，消耗少量 EU），
   将催化剂涂覆到结构中的电解质层表面。涂覆完成前机器无法发电。

2. **运行消耗：** 催化剂在运行过程中缓慢消耗（退化），
   UI 上显示"催化剂剩余量"百分比条。

3. **自动补充：** 当催化剂剩余量低于阈值（可配置，默认 25%）时，
   机器自动从 Input Bus 中取用新的催化剂物品进行补涂。
   补涂过程不中断发电（热补涂），但效率短暂降低 5% 持续 5 秒。

4. **催化剂耗尽：** 如果催化剂降至 0% 且 Input Bus 中无新催化剂，
   机器进入"催化剂耗尽"停机状态。
   同时通过 Output Bus 排出"废催化剂粉"（含残余贵金属，可回收）。

**催化剂物品规格（按变体）：**

| 变体 | 催化剂物品 | 单次涂覆消耗 | 满涂覆运行时间 |
|------|----------|------------|-------------|
| DMFC | 碳载铂催化剂板 (Pt/C Catalyst Plate) | 1 | ~50 小时 |
| SOFC | 镍金属陶瓷催化剂粉 (Ni-YSZ Catalyst Dust) | 4 | ~20 小时 |
| MCFC | 镍催化剂板 (Nickel Catalyst Plate) | 4 | ~25 小时 |

**催化剂品质升级：**

每种催化剂有三个品质等级，高品质催化剂运行时间更长：

| 品质 | 后缀 | 运行时间倍率 | 制造要求 |
|------|------|-----------|---------|
| 标准 | — | ×1 | 基础化学配方 |
| 纳米级 | (Nano) | ×2 | 需要纳米级合成（高一等级） |
| 单原子级 | (Single-Atom) | ×4 | 需要单原子沉积工艺（高两等级） |

**废催化剂回收：**

通过 Output Bus 输出的"废催化剂粉"可在化学反应釜中回收：
- DMFC 废催化剂 → 回收少量铂粉（贵金属回收，经济激励）
- SOFC/MCFC 废催化剂 → 回收镍粉（价值较低但仍有意义）

#### 共享机制：启动序列

所有燃料电池变体在达到满功率前都需要一个短暂的启动阶段：

1. **催化剂涂覆（首次/补充后）：** 机器从 Input Bus 取用催化剂物品，
   涂覆到电解质层上。首次涂覆约 10 秒，期间不发电。

2. **冷启动（加热到工作温度）：** 消耗少量外部 EU（或内部缓冲）将电池堆加热到
   工作温度。时间因变体而异（DMFC: 5秒，SOFC: 30秒，MCFC: 20秒）。

3. **热待机（燃料中断）：** 如果燃料耗尽但电池堆仍处于高温状态，
   将进入待机模式。在热衰减窗口内恢复燃料供给可跳过冷启动阶段。

4. **热失控保护：** 如果工作温度超出安全范围
   （由于过载或冷却失效），电池将紧急关机。
   需要使用橡胶锤手动重启。

### 3.2 变体 1：DMFC — 直接甲醇燃料电池

#### 现实科学基础

直接甲醇燃料电池在阳极直接氧化甲醇（CH₃OH），无需先将其重整为氢气。
这消除了对制氢基础设施的需求，使其成为操作最简单的燃料电池。

```
阳极反应:  CH₃OH + H₂O  -->  CO₂ + 6H⁺ + 6e⁻
阴极反应:  3/2 O₂ + 6H⁺ + 6e⁻  -->  3H₂O
总反应:    CH₃OH + 3/2 O₂  -->  CO₂ + 2H₂O + 电能
```

#### 技术规格

| 参数 | 数值 | 说明 |
|-----|------|-----|
| **电压等级** | MV | 入门级燃料电池 |
| **电压输出** | 128 EU/t 每电池层 | V[MV] |
| **最大安培数** | 2A 每电池层 | 256 EU/t 每层 |
| **燃料** | 甲醇（流体） | 满载时 10 mB/t |
| **氧化剂** | 氧气（流体） | 满载时 15 mB/t |
| **副产物（流体）** | CO₂（气体） | 5 mB/t |
| **副产物（流体）** | 水 | 10 mB/t |
| **工作温度** | 60~120 °C | 低温 |
| **电能转换效率** | 25%（基础值） | 低，但使用便利 |
| **最大电池层数** | 4 | 最大总输出 1024 EU/t |
| **启动时间** | 5 秒 | 非常快 |

#### 外壳与电解质

| 组件 | 材料 | 方块/物品 |
|------|-----|----------|
| 外壳 | 钢 | 钢制机器外壳 |
| 阳极通道 | 石墨方块 | 新增：石墨电极方块 |
| 电解质膜 | Nafion 型质子交换膜 | 基于 ION_EXCHANGE_MEMBRANE 的方块 |
| 阴极通道 | 石墨方块 | 与阳极相同 |
| 催化剂（物品输入） | 碳载铂催化剂板 (Pt/C Catalyst Plate) | 通过 Input Bus 输入，机器内部涂覆到电解质膜两面 |
| 废催化剂（物品输出） | 废铂催化剂粉 (Spent Pt Catalyst Dust) | 通过 Output Bus 输出，可在化学反应釜回收铂 |

#### 独特机制：甲醇渗透

DMFC 在现实中存在一个名为"甲醇渗透（methanol crossover）"的问题——
甲醇分子会穿透质子交换膜到达阴极，浪费燃料并降低效率。

- **基础效率仅为 25%**，是所有燃料电池中最低的
- **效率惩罚随甲醇浓度增加**：如果燃料输入速率超过电池堆的消耗能力，
  渗透量增加，效率进一步降低
- **最优操作**：以最大燃料输入速率的 70-80% 运行可获得最佳效率
- 该机制奖励精细的燃料管理，而非简单地将输入拉满

#### 科技树定位

- **在 MV 解锁** — 最早可用的燃料电池
- **相比 MV 发电机的优势**：无需制氢；甲醇相对容易生产
  （木头 → 木炭 → 甲醇，或化学合成）
- **劣势**：低效率意味着每 EU 消耗更多燃料
- **适用场景**：适合甲醇来源丰富但尚无制氢产线的基地

### 3.3 变体 2：SOFC — 固体氧化物燃料电池

#### 现实科学基础

固体氧化物燃料电池使用陶瓷电解质——氧化钇稳定氧化锆（YSZ），
在高温下传导氧离子（O²⁻）。其核心优势是极高的燃料灵活性——
可以使用氢气、天然气、一氧化碳或任何可重整的碳氢化合物。

```
使用 H₂ 燃料:
  阳极:  H₂ + O²⁻  -->  H₂O + 2e⁻
  阴极:  1/2 O₂ + 2e⁻  -->  O²⁻

使用 CO 燃料:
  阳极:  CO + O²⁻  -->  CO₂ + 2e⁻
  阴极:  1/2 O₂ + 2e⁻  -->  O²⁻

使用 CH₄ 燃料（内部重整）:
  阳极:  CH₄ + 4O²⁻  -->  2H₂O + CO₂ + 8e⁻
  阴极:  2O₂ + 8e⁻  -->  4O²⁻
```

#### 技术规格

| 参数 | 数值 | 说明 |
|-----|------|-----|
| **电压等级** | HV ~ EV | 中期主力 |
| **电压输出** | 512 EU/t 每电池层 (HV) | V[HV] 基准 |
| **最大安培数** | 4A 每电池层 | 2048 EU/t 每层 |
| **燃料（选项 1）** | 氢气（流体） | 满载时 20 mB/t |
| **燃料（选项 2）** | 甲烷/天然气（流体） | 满载时 8 mB/t |
| **燃料（选项 3）** | 一氧化碳（流体） | 满载时 15 mB/t |
| **燃料（选项 4）** | 炼厂气（流体） | 满载时 12 mB/t |
| **氧化剂** | 氧气（流体） | 满载时 20 mB/t |
| **副产物（流体）** | H₂O 和/或 CO₂ | 取决于燃料类型 |
| **副产物（流体）** | 高压蒸汽 | 30 mB/t（余热回收！） |
| **工作温度** | 700~1000 °C | 高温 |
| **电能转换效率** | 55%（基础值） | 高 |
| **联合循环效率** | 80% 以上（含蒸汽回收） | 热电联产 (CHP) |
| **最大电池层数** | 6 | 最大总输出 49152 EU/t |
| **启动时间** | 30 秒 | 慢——需要加热 |

#### 外壳与电解质

| 组件 | 材料 | 方块/物品 |
|------|-----|----------|
| 外壳 | 钛 | 钛稳定外壳 |
| 阳极通道 | Ni-YSZ 金属陶瓷方块 | 新增：镍-氧化锆电极方块 |
| 电解质层 | YSZ 陶瓷方块 | 新增：氧化钇稳定氧化锆方块 |
| 阴极通道 | LSM 钙钛矿方块 | 新增：锶掺锰酸镧方块 |
| 催化剂（物品输入） | 镍金属陶瓷催化剂粉 (Ni-YSZ Catalyst Dust) | 通过 Input Bus 输入，机器内部涂覆到阳极表面（自催化） |
| 废催化剂（物品输出） | 废镍催化剂粉 (Spent Ni Catalyst Dust) | 通过 Output Bus 输出，可在化学反应釜回收镍 |

#### 独特机制：多燃料灵活性 + 余热回收

**多燃料：**
- SOFC 接受 4 种不同燃料，各有不同效率：
  - 氢气：60% 效率（最高，但制氢成本高）
  - 甲烷：55% 效率（良好，燃料来源丰富）
  - 一氧化碳：45% 效率（可接受，来自气化工艺）
  - 炼厂气：40% 效率（最低，但利用了废弃副产物）
- 电池自动检测输入的燃料类型并相应调整配方。
  如果同时存在多种燃料，按效率优先级选择。

**余热回收（热电联产）：**
- SOFC 工作在 700-1000 °C，产生大量废热
- 废热以**高压蒸汽**形式通过流体输出仓排出
- 蒸汽可管道输送到大型蒸汽涡轮进行二次发电
- 这构成了**燃料电池 + 涡轮联合循环**，总效率可达 80% 以上
- 如果不回收蒸汽，多余的热量会加速催化剂退化

#### 科技树定位

- **在 HV 解锁** — 第一台"正经"的燃料电池
- **相比内燃引擎的优势**：更高效率、多种燃料选择、余热回收可组联合循环
- **劣势**：启动时间长、需要陶瓷材料（新配方链）、高温下催化剂退化
- **适用场景**：理想的基地电力骨干，特别是与蒸汽涡轮配合使用时

### 3.4 变体 3：MCFC — 熔融碳酸盐燃料电池

#### 现实科学基础

熔融碳酸盐燃料电池使用锂碳酸盐和钾碳酸盐的熔融混合物（Li₂CO₃/K₂CO₃）
作为电解质。其最显著的特征是阴极反应**需要 CO₂ 作为输入**，
与氧气一同参与反应。这使其非常适合碳捕获应用。

```
阳极反应:  H₂ + CO₃²⁻  -->  H₂O + CO₂ + 2e⁻
阴极反应:  1/2 O₂ + CO₂ + 2e⁻  -->  CO₃²⁻

注意：CO₂ 在阴极被消耗，在阳极被释放。
净效果是 CO₂ 从阴极侧转移到阳极侧，
实现对烟气流中碳的捕获。
```

#### 技术规格

| 参数 | 数值 | 说明 |
|-----|------|-----|
| **电压等级** | EV ~ IV | 高级燃料电池 |

#### 独特机制：CO₂ 捕获循环

MCFC 的标志性机制是**强制 CO₂ 输入**：

1. **CO₂ 作为氧化剂组分**：阴极同时需要氧气和二氧化碳。
   没有 CO₂ 输入，电池完全无法运行。

2. **CO₂ 来源选项**：
   - 来自化工过程的瓶装 CO₂
   - 内燃引擎的排气（形成工业共生！）
   - MCFC 自身阳极排气的回路（部分自循环，但仍需要净 CO₂ 输入）

3. **碳捕获增值**：阳极侧排出的 CO₂ 是**浓缩的、高纯度 CO₂ 气流**——
   纯度远高于混合输入。这种浓缩 CO₂ 对下游化工工艺更有价值
   （例如干冰、碳酸化、尿素合成）。

4. **共生设计**：理想配置是将 MCFC 与大型内燃引擎搭配：
   ```
   内燃引擎排气（富 CO₂）--> MCFC 阴极输入
   MCFC 阳极输出（高纯 CO₂）--> 化工厂（增值产品）
   MCFC 蒸汽输出 --> 蒸汽涡轮（额外发电）
   ```
   这种三重共生（内燃机 + 燃料电池 + 涡轮）代表了 EV~IV 等级
   高效发电的巅峰形态。

#### 科技树定位

- **在 EV 解锁** — 面向成熟基地的高级燃料电池
- **优势**：CO₂ 捕获创造工业协同效应，功率密度高
- **劣势**：需要 CO₂ 供给基础设施，流体管线复杂
- **适用场景**：与内燃引擎搭配实现联合循环 + 碳捕获

## 4. 多方块 B：可逆固体氧化物电池 (rSOC)

### 概念

rSOC 是一台双模式多方块，可在两种工作模式间切换：

- **SOFC 模式（发电）**：消耗 H₂ + O₂，产出 H₂O + 电力
- **SOEC 模式（电解）**：消耗 H₂O + 电力，产出 H₂ + O₂

这使其成为一个电化学储能系统——类似可充电电池，
但使用氢气作为能量载体，而非内部化学状态。

### 现实科学基础

可逆固体氧化物电池是 NASA（用于火星栖息地电力/生命维持系统）
和欧洲研究联盟正在开发的前沿技术。
相同的 YSZ 陶瓷电解质可根据施加电压的极性在两个方向上传导 O²⁻ 离子。

```
SOFC 模式（发电）:
  阳极:  H₂ + O²⁻  -->  H₂O + 2e⁻
  阴极:  1/2 O₂ + 2e⁻  -->  O²⁻
  净反应: H₂ + 1/2 O₂  -->  H₂O + 电能

SOEC 模式（电解）:
  阴极:  H₂O + 2e⁻  -->  H₂ + O²⁻
  阳极:  O²⁻  -->  1/2 O₂ + 2e⁻
  净反应: H₂O + 电能  -->  H₂ + 1/2 O₂

往返效率: ~50%
```

### 技术规格

| 参数 | 发电模式 | 电解模式 |
|-----|---------|---------|
| **电压等级** | LuV | LuV |
| **电压** | 131072 EU/t 输出 | 131072 EU/t 输入 |
| **安培数** | 2A 输出 | 2A 输入 |
| **燃料/输入** | H₂ (20 mB/t) + O₂ (10 mB/t) | H₂O (20 mB/t) |
| **输出** | H₂O (20 mB/t) | H₂ (20 mB/t) + O₂ (10 mB/t) |
| **工作温度** | 700~850 °C | 700~850 °C |
| **效率** | 55% | 55%（电能→化学能） |
| **往返效率** | ~50%（H₂→H₂） | 包含两次转换 |

### 结构布局

rSOC 采用对称结构，反映其双向工作特性：

```
正面视图：              侧面截面：

  CCCCC                   C = 外壳（铱）
  CCCCC                   E = 电解质（YSZ 陶瓷）
  CSCCC                   A = 电极（Ni-YSZ，双功能）
                          H = 加热线圈（维持工作温度）

  第 0 层    第 1~4 层    第 5 层
  (端盖)    (电池层)     (端盖)

  CCCCC     CAEAC        CCCCC
  CCCCC     CHEHC        CCCCC
  CSCCC     CAEAC        CCCCC
```

**加热线圈** 是必需的，因为 rSOC 在两种模式下都需要维持 700 °C 以上。
发电模式下反应是放热的，启动后可自维持。
电解模式下反应是吸热的，线圈必须主动加热。

### 仓室配置

|---------|------|------|-----|

| 流体输出仓 | 端盖 / 外壳 | 2~4 | 发电时 H₂O / 电解时 H₂+O₂ |
| **物品输入总线（催化剂）** | **端盖 / 外壳** | **1** | **Ni-YSZ 催化剂粉输入，涂覆到电极上** |
| 物品输出总线（废催化剂） | 端盖 / 外壳 | 0~1 | 废镍催化剂粉输出 |

特殊之处：每次模式切换额外消耗 1% 催化剂剩余量（热应力加速退化）。

### 独特机制：模式切换

1. **模式切换**：玩家使用橡胶锤敲击控制器切换模式。
   或者，可以通过红石信号触发自动切换。

2. **过渡时间**：切换模式需要 10 秒。在此期间电池不产生输出，
   消耗少量维持能量来保持陶瓷堆的工作温度。

3. **自动模式（可选）**：配合红石信号：
   - 高电平 = 电解模式（将电能储存为 H₂）
   - 低电平 = 发电模式（从储存的 H₂ 产生 EU）
   这实现了自动化能量缓冲：多余电力 → H₂ → 储存 → 需要时发电

4. **热循环惩罚**：每次模式切换都会对陶瓷堆造成热应力，
   略微增加催化剂退化速度。不鼓励频繁切换。
   最优使用方式：在一种模式下长时间运行，仅在需要时切换。

### 科技树定位

- **在 LuV 解锁** — 高级能量管理工具
- **优势**：双向运行实现氢气储能
- **劣势**：50% 往返效率意味着显著的能量损失；
  昂贵的陶瓷和铱制造成本
- **适用场景**：聚变反应堆的削峰填谷（低负载时储存多余电力，
  高需求时发电），或为其他工艺生产氢气

## 5. 多方块 C：量子隧穿燃料电池

### 概念

量子隧穿燃料电池（QTFC）利用量子力学隧穿效应绕过电化学反应中的
经典活化能势垒。在传统燃料电池中，大量能量在克服活化过电位
——电极表面电子转移的能量势垒——时被损耗。QTFC 使用工程化的
量子点阵列，允许电子隧穿这些势垒，实现接近热力学极限的效率。

### 虚构科学基础

```
经典燃料电池电子路径：
  反应物 --> [活化势垒] --> 产物 + e⁻
  损耗：30-40% 的理论能量用于克服势垒

量子隧穿路径：
  反应物 --> [量子点阵列] ~~隧穿~~> 产物 + e⁻
  电子波函数通过量子约束效应穿透势垒
  损耗：仅 5-15%（残余退相干损耗）

要求：
  - 低温环境以抑制热退相干
  - 同位素纯净燃料（随机同位素会造成波函数散射）
  - 超导量子点基底
```

#### 1. 低温维持

- 如果冷却剂供给中断，温度升高，效率迅速下降
- T > 50K 时：效率降至 60%（量子相干性丧失）
- T > 100K 时：电池进入紧急关机（超导体失超）
- 热氦气输出可管道输送到氦液化器，形成冷却循环回路

#### 2. 量子相干度指示器

独特的 UI 元素显示"量子相干度"百分比：
- 100% 相干度 = 90% 电能转换效率（最大值）
- 相干度降低的原因：
  - 温度升高（最重要的因素）
  - 燃料不纯（混入普通 H₂ 与 D₂ 造成散射）
  - 催化剂随时间退化
- 恢复相干度的方法：
  - 降低温度（增加冷却剂供给）
  - 使用同位素纯净的氘
  - 更换退化的量子点阵列

#### 3. 同位素燃料纯度

QTFC 设计使用氘作为燃料：
- **氘**：90% 基础效率（预期燃料）
- **普通氢气**：70% 效率（同位素散射损耗）
- **氚**：85% 效率（更重的同位素，散射小于 H，但不如 D）
- 这激励玩家建立氘分离产线

### 科技树定位

- **在 ZPM 解锁** — 终局发电设备
- **优势**：极高效率（90%），清洁运行（重水副产物有用处）
- **劣势**：需要低温基础设施（液氦供应链），
  昂贵的量子点阵列，氘燃料生产
- **适用场景**：ZPM 级工厂的高端高效电力，
  特别是与氦气回收循环配合使用时

## 6. 共享系统

### 6.1 催化剂退化系统

所有燃料电池都使用会随时间退化的催化剂。催化剂以物品形式通过 Input Bus 输入，
机器内部自动涂覆到电解质层上，运行中缓慢消耗，在标准 GT 维护仓之外
增加了额外的维护维度。

#### 退化模型

```
催化剂剩余量: 100%（满涂覆）--> 0%（耗尽）

每小时运行的退化速率（标准品质催化剂）:
  DMFC（碳载铂催化剂板）:           -2% / 小时  (铂耐用但昂贵)  → ~50 小时
  SOFC（镍金属陶瓷催化剂粉）:       -5% / 小时  (镍在高温下退化更快) → ~20 小时
  MCFC（镍催化剂板）:              -4% / 小时  (中等温度，中等退化) → ~25 小时
  rSOC（Ni-YSZ 双功能催化剂粉）:   -3.3% / 小时 (外加每次模式切换 +1%) → ~30 小时
  QTFC（量子点催化剂基板）:         -1% / 小时  (低温保护，退化最慢) → ~100 小时

退化对效率的影响:
  100~75%: 无影响（正常运行）
  75~50%:  效率惩罚 -10%
  50~25%:  效率惩罚 -25%
  25%:     触发自动补涂（如果 Input Bus 有新催化剂）
  25~0%:   效率惩罚 -50% + UI 警告
  0%:      电池停机，必须补充催化剂
```

#### 催化剂补充流程

1. **自动补涂**：催化剂剩余量降至 25% 时，机器自动从 Input Bus
   取用新催化剂进行补涂，催化剂剩余量回到 100%。
   补涂过程不中断发电（热补涂），但效率短暂降低 5% 持续 5 秒。

2. **手动补涂**：玩家也可以在任意时刻通过控制器 UI 按钮
   手动触发补涂（前提是 Input Bus 有催化剂物品）。

3. **催化剂耗尽停机**：如果降至 0% 且 Input Bus 中无新催化剂，
   机器进入"催化剂耗尽"停机状态。
   同时通过 Output Bus 排出"废催化剂粉/基板"。

#### 废催化剂回收

通过 Output Bus 输出的废催化剂可在化学反应釜中回收：

| 废催化剂 | 回收产物 | 回收率 | 说明 |
|---------|---------|-------|------|
| 废铂催化剂粉 (DMFC) | 少量铂粉 | ~30% | 贵金属回收，经济激励显著 |
| 废镍催化剂粉 (SOFC/MCFC/rSOC) | 镍粉 | ~50% | 镍价值较低但量大 |
| 退相干量子点基板 (QTFC) | 量子点催化剂基板 | ~60% | 重新制备量子点层 |

#### 催化剂品质等级

每种催化剂有三个品质等级，高品质催化剂运行时间更长：

| 品质 | 后缀 | 运行时间倍率 | 制造要求 |
|------|------|-----------|---------|
| 标准 | — | ×1 | 基础化学配方 |
| 纳米级 | (Nano) | ×2 | 需要纳米级合成工艺（高一等级） |
| 单原子级 | (Single-Atom) | ×4 | 需要单原子沉积工艺（高两等级） |

#### 全催化剂物品汇总

| 催化剂物品 | 用于 | 材料基础 | 标准运行时间 |
|-----------|------|---------|------------|
| 碳载铂催化剂板 (Pt/C Catalyst Plate) | DMFC | 铂 + 碳 | ~50 小时 |
| 镍金属陶瓷催化剂粉 (Ni-YSZ Catalyst Dust) | SOFC | 镍 + YSZ | ~20 小时 |
| 镍催化剂板 (Nickel Catalyst Plate) | MCFC | 镍 | ~25 小时 |
| Ni-YSZ 双功能催化剂粉 (Ni-YSZ Bifunctional Catalyst Dust) | rSOC | 镍 + YSZ | ~30 小时 |
| 量子点催化剂基板 (Quantum Dot Catalyst Substrate) | QTFC | 超导体 + 量子点 | ~100 小时 |

### 6.2 热管理系统

#### 温度模型

每种燃料电池都有工作温度范围和最优温度：

```
              过冷         |   最优范围    |   过热
                          |              |
DMFC:   ----[40]----[60]=====[80]====[120]----[150]----
SOFC:   ----[500]---[700]====[850]===[1000]---[1200]---
MCFC:   ----[400]---[600]====[650]===[700]----[900]----
rSOC:   ----[500]---[700]====[775]===[850]----[1000]---
QTFC:   ----[N/A]---[4]======[10]====[20]-----[50]----  (开尔文!)
```

**低于最优范围**：效率降低，反应变慢
**在最优范围内**：满效率，稳定运行
**高于最优范围**：催化剂退化加速，存在热失控风险

#### 温度控制

- **低温电池（DMFC）**：自然空气冷却，几乎不需要热管理
- **高温电池（SOFC/MCFC/rSOC）**：启动时需要加热线圈；
  达到工作温度后可自维持；高负载时可能需要冷却
- **低温电池（QTFC）**：需要持续供给低温冷却剂

### 6.3 效率曲线模型

燃料电池的效率不是固定值——它随负载变化：

```
效率
  ^
  |         .----.
  |        /      \
  |       /        \
  |      /          \
  |     /            \
  |    /              \
  |   /                \---
  |--/
  +--------------------------> 负载 %
  0   20   40   60   80  100

峰值效率出现在 ~60-70% 负载
极低负载时效率下降（寄生损耗主导）
极高负载时效率下降（物质传输限制）
```

该曲线引导玩家：
1. 合理确定燃料电池阵列的尺寸（不要为实际负载配置过多电池层）
2. 考虑部分负载运行以获得更好的燃料经济性
3. 权衡多个小型燃料电池 vs 一个大型燃料电池

### 配方链示例（以 SOFC 为例）

```
=== 结构方块制造 ===
步骤 1: ZrO₂ 粉 + Y₂O₃ 粉 --> YSZ 粉（搅拌机）
步骤 2: YSZ 粉 --> YSZ 陶瓷方块（压缩机 + 高炉烧结）
步骤 3: Ni 粉 + YSZ 粉 --> Ni-YSZ 金属陶瓷方块（高炉共烧结）
步骤 4: La₂O₃ + SrCO₃ + MnO₂ --> LSM 粉（化学反应釜）
步骤 5: LSM 粉 --> LSM 钙钛矿方块（高炉烧结）
步骤 6: 组装: 钛框架 + YSZ + Ni-YSZ + LSM + 线缆 --> SOFC 电池层

=== 催化剂制造（持续消耗品）===
步骤 A: Ni 粉 + YSZ 粉 --> 镍金属陶瓷催化剂粉 ×4（搅拌机，与方块不同配比）
步骤 B: [可选升级] 催化剂粉 + 纳米碳管 --> 纳米级催化剂粉（化学反应釜）
步骤 C: [可选升级] 纳米级催化剂粉 + 单原子沉积液 --> 单原子级催化剂粉（精密组装机）

=== 废催化剂回收 ===
步骤 R: 废镍催化剂粉 + 盐酸 --> 镍粉 + 废液（化学反应釜，~50% 回收）
```

## 8. 平衡设计哲学

### 发电等级定位

```
                   EU/t 输出范围
等级    |  内燃引擎    |  涡轮    |  燃料电池    |  聚变    |
--------|-------------|---------|-------------|---------|
MV      |  96~384     |  无      |  256~1024   |  无      |
HV      |  384~1536   |  2048   |  1024~12288 |  无      |
EV      |  1536~6144  |  8192   |  8192~65536 |  无      |
IV      |  无          |  32768  |  32768~262k |  无      |
LuV     |  无          |  无     |  262k (rSOC)|  131k+  |
ZPM     |  无          |  无     |  1M~4M(QTFC)|  524k+  |
```

### 燃料电池 vs 现有发电机：设计意图

| 维度 | 内燃引擎 | 燃料电池 | 设计理由 |
|------|---------|---------|---------|
| **燃料消耗** | 中等 | 低（效率更高） | 燃料电池奖励燃料链投资 |
| **基础设施成本** | 低（只需燃料） | 高（催化剂、膜、陶瓷） | 燃料电池前期投入更大 |
| **维护** | 标准 | 催化剂退化 | 燃料电池需要持续的材料投入 |
| **灵活性** | 单一燃料 | 多燃料（SOFC） | 奖励复杂配置 |
| **启动时间** | 即时 | 5~60 秒 | 燃料电池适合连续运行 |
| **联合循环** | 无 | 有（SOFC/MCFC + 涡轮） | 奖励复杂管线设计 |
| **协同效应** | 独立运行 | MCFC + 内燃引擎排气 | 鼓励工业生态系统 |

### 核心平衡原则

> **燃料电池应当比内燃引擎每单位燃料产出更多 EU，
> 但需要显著更多的基础设施、材料和维护来实现这一点。**

只是想要电力的玩家应该使用内燃引擎。
投资于催化剂生产、陶瓷制造、热管理和流体布线的玩家，
应当获得更优的燃料效率和独特的工业协同效应作为回报。
